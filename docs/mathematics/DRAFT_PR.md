# Mathematics foundation: Grade 1–12 graph, deterministic practice and separate exam journeys

Adds an isolated mathematics foundation on stable main b578c78: a 200-competency versioned DAG with separate provisional board mappings, fourteen seeded original practice families, bounded exact answer equivalence, fixed multi-session program contracts and a mobile React preview. JEE Main, JEE Advanced and GRE Quant share competency IDs while retaining distinct journey/program completion; CUET is a registry placeholder.

The preview supports activity expansion, draft/hint/solution persistence, resumed stages, deterministic feedback and structured synthetic evidence export. It changes no production navigation, estimator, ledger union, evidence eligibility, English/Tamil or protected essay work. Production integration awaits a host adapter, existing authenticated identity/persistence and read-only learner evidence views. All generated items remain provisional practice and never update proficiency.

Official curriculum and exam websites returned network-proxy 403, so board/source editions remain unverified and current timing/scoring are intentionally unconfigured. Timed testing is disabled. Twelve programs have executable provisional practice templates; 188 are scaffolds. Full educator-authored lessons and validated transfer tasks are outstanding. No scientific/real-child effectiveness claims.
