# Mathematics foundation v1: curriculum, practice and canonical integration preparation

Adds a 200-competency Grade 1–12 foundation, fourteen deterministic original practice families, fixed resumable program contracts and a synthetic mobile school/competitive-exam preview. Board mappings remain provisional. JEE Main, JEE Advanced and GRE share mathematical competency identity while retaining separate program progress; CUET remains a placeholder. No merge or deployment is authorized.

The follow-up freezes the accepted curriculum bytes and audits all 12 executable practice programs and all 14 families. None is a complete educator-reviewed instructional program. The audit documents artificial prerequisite chains, substantive coverage gaps, narrow difficulty/exam-style coverage and duplicate stems hidden by unused parameters. No curriculum or generator expansion is included.

A new practice-only adapter binds activity records to the existing learner identity, canonical content/events, ledger/store and eligibility gate. Exact answer codecs preserve raw responses in required sidecars. Shared profile projection delegates to the existing core. The integration test follows one learner from school fractions into GRE: one competency/history, separate resumable progress, all provisional responses held and no mastery changes. Semantic item identity folds disguised repeated questions. Completion deduplicates activity IDs and remains separate from proficiency.

The unchanged production framework loader is English-specific. A named in-memory host-registration fixture tests the existing gate; this is not production MATH registration. Authenticated account integration and atomic artifact/content/event persistence are still required. Transport-only difficulty fields are not calibrated mathematics estimates. Exam readiness, timed testing and scoring remain disabled; current official specifications could not be verified through the environment's network.

No estimator, mastery policy, evidence eligibility rule, English/Tamil source, essay branch or unrelated test is changed. Two existing shared-core frozen research fingerprint failures remain visible; they reproduced on untouched main and have not been rewritten.
