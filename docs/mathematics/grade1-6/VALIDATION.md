## What was exercised

Mathematical oracle checks independently calculate the 18 expected answers (addition, products, equivalent fractions, comparison by cross multiplication). Rational-equivalent answers are accepted where appropriate; division by zero and unsupported syntax are rejected. Every question has a worked solution, contrast/error feedback, a stable native item/family and provisional gate.

Tests cover independent and assisted/repeated practice, sensible counting/equal-group/fraction prerequisites, no forced unrelated chain, a single wrong response not diagnosing a skill gap, optional-extra-practice support for fresh independent successes, fixed stages, native held evidence, persistent model state after a browser context closes, malformed model payloads, keyboard submission, 320–768px body fit, reopening finished activities, stale sequence conflicts, ownership/CSRF boundaries, failure recovery, early-retention rejection and controlled-clock delayed completion. Historical fractions receipts remain readable alongside new program receipts; events retain append order. School and exam progress are kept separate without splitting competency identity.

[synthetic-results.json](synthetic-results.json) is generated by the executable report script, not manually invented learner data. It describes fixed synthetic response patterns only. The browser screenshots are from the actual new interface with synthetic pupils.

## Setup issues encountered and corrected

The first Grade 1 browser setup attempted registration before the CSRF-cookie request completed. The test now waits for account initialization. Regression attempts initially selected a non-Tamil service on port 4176 and omitted the system Chromium environment variable; corrected commands above use an explicit Tamil preview on 4196 and system Chromium. The integrated baseline introduced an essay database migration absent from the old local preview database; applying that existing migration fixed account deletion. Repeated local synthetic registrations eventually exercised the real registration throttle (429); restarting the isolated test API reset its in-memory test state, with no rate-limit changes. The final runs listed above passed after these setup corrections.
