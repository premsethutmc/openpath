# Class 5: the taught method for each topic

The reference the step help is built against (owner's direction, 18 Nov 2026). Written from standard Indian school
practice; where a topic has more than one accepted method, the commonest is first and the others are further tabs
(`methods@1`). "Built" means the method is written as a rule in `packages/learning/src/worked-out.ts`, shown with its
written layout where it has one, and proved on every question by `frontend/src/year/worked-out.test.ts`.

| Topic | Taught method (tab 1) | Other accepted ways | Built |
| --- | --- | --- | --- |
| Addition of whole numbers | Columns, ones first, carry to the next column | By place value (add the parts) | yes |
| Subtraction of whole numbers | Columns, ones first, borrow from the next column | By place value | yes |
| Division by a 1- or 2-digit number | Long division: the bracket, one digit at a time | In easy parts | yes |
| Division with a remainder | Long division; the last row is the remainder | Check: quotient × divisor + remainder | yes |
| Prime test, smallest prime factor | Try each prime in turn up to the square root | | yes |
| Multiplication by 1 digit | Columns, ones first, carrying | Tens and ones separately | yes (two tabs; also by 90, 400: zeros first) |
| Multiplication by 2 digits | Columns: one row for each digit of the multiplier, then add the rows | Lattice | no: there is no plain question type (47 × 36 = ?) yet, only partial-product and lattice questions |
| Rounding | Look at the digit to the right: 5 or more goes up | Number line: which is nearer | partly (line) |
| Estimating | Round each number first, then work | | partly (first steps) |
| Place value, lakhs and crores | Place-value chart; a zero for every empty place | Commas, Indian and international | partly (chart) |
| Factors | Pair them: 1 × n, 2 × ?, 3 × ? … | | no |
| HCF | Prime factorisation: common primes | Listing common factors; division method | yes (three tabs) |
| LCM | Prime factorisation: every prime, highest count | Listing multiples; common division ladder | yes (up to three tabs) |
| Equivalent fractions | Multiply (or divide) top and bottom by the same number | | partly (first steps) |
| Lowest terms | Divide top and bottom by their HCF | Divide by common factors in turn | no |
| Mixed ↔ improper fractions | Whole × denominator + numerator, over the denominator | Divide for the other direction | no |
| Adding and subtracting unlike fractions | Same denominator (the LCM), then add the tops | | partly (first steps) |
| Fraction × whole number | Multiply the top; simplify | Repeated addition | no |
| Decimals: add and subtract | Line up the decimal points; then as whole numbers | | no |
| Decimals × and ÷ by 10, 100, 1000 | Move the digits past the decimal point | | no |
| Percentages | Out of 100: fraction with denominator 100 | | no |
| Integers: add and subtract | Number line: right to add, left to subtract | Sign rules | partly (line) |
| Unit conversion | Multiply by how many small units make one big one | | partly (first steps) |
| Time: adding durations | Add minutes, carry every 60 into hours | | no |
| Perimeter | Add every side; rectangle: 2 × (length + breadth) | | no |
| Area of a rectangle | Length × breadth (rows of unit squares) | Counting squares | partly (grid) |
| Angles | Compare with a right angle; measure with a protractor | | partly |
| Bar charts, tables, pie charts | Read the scale; one bar or row at a time | | no |
| Patterns | Find the rule from one term to the next | | no |
