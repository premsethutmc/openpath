# Reading → summary → own argument: candidate increment

Route: non-pilot `?experience=english-workspace`, select a goal/challenge, then **Practise reading into your own writing**. No API configuration needed and no paid calls are made. Existing API writing evaluation and Claude's spelling work are untouched.

## Learning loop

- Three self-selected complexity levels, each with three original, distinct passages: worked example, supported practice, reserved independent passage (nine total). School/community contexts for foundation; qualified practical decisions and selection/causal limits at higher levels.
- Five goal choices adjust the own-response prompt. These are preferences, not age placement or calibrated CAT/GRE/GMAT tasks.
- Worked example teaches central point, observation versus inference, qualified summary, and evidence-to-recommendation connection. It uses a different passage, not a replacement for the learner's text.
- Learner chooses a main idea, authors a source summary, and writes their own reasoned recommendation. Both writing fields and choice are required before submission.
- Main-idea feedback is keyed. Free writing is **unassessed**, with a source-fidelity/reasoning self-review checklist and separate learner-authored revision.
- Fresh check hides the worked example and feedback until submission. Starting reserves the passage across goals in this browser; revisiting resumes the same attempt. No automatic reset masquerades as fresh evidence. A single fresh check per level is the present inventory limit.
- Completed practice is archived before switching. After the independent attempt, earlier supported work can be viewed for reflection, explicitly not a measured gain.
- Local drafts, submitted work, revisions, and exposure flags survive reload/navigation. Storage failures are visible; a failure to archive practice blocks transition.

## Limits and next increments

This is a small synthetic candidate teaching bank, not a comprehensive reading curriculum or adaptively placed proficiency test. There is one main-idea question per attempt; inference/source-fidelity/summary and argument quality require reliable assessment. No keyword score or deterministic grammar substitute is invented. There is no delayed retention task, longitudinal mastery integration, or cross-device exposure tracking. Clearing browser data loses drafts and exposure history. The module is not for real learner personal data and does not change pilot access.

Next: educator review of passages/rubric, more disjoint passage families, source-aware API assessment with exact evidence and conservative uncertainty, calibrated scaffold selection, delayed transfer tasks, then learner-record integration. Keep self-revision separate from independent evidence.
