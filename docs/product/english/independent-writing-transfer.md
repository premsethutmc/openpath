# Independent writing transfer (candidate, synthetic only)

The argument workspace now separates coached revision from a subsequent independent writing attempt. Finishing a revision does not establish transfer, and passing recognition questions does not establish writing ability.

## Journey and provenance

After the initial/for/against/revision cycle, the learner can explicitly open an authored transfer topic. Opening reserves the topic in the existing essay evidence ledger before it is shown. The reserved prompt resumes after reload. Leaving consumes the topic without an inferred result. A completed cycle permits one submitted transfer attempt, not unlimited opportunities to select a favorable result.

The attempt screen hides earlier writing, coaching questions, worked examples and concept practice. It asks for a fresh own-word response and explicit synthetic-test and unaided declarations. This is unproctored: external help, other tabs and semantic paraphrases cannot be reliably detected. Freshness is scoped to this device learner's recorded history; separate goal/challenge histories are not a global exposure registry.

Unsaved editor text is not persisted. The interface says this before the learner leaves. Committed writing remains in the existing ledger and is never replaced by model prose.

## Evaluation

The existing shared argument observation interface receives the new task and invented response only, without prior writing or coaching. The dedicated transfer stage rejects prior-context fields. The same strict provenance/quote/schema validation applies. The output is tentative quoted concerns, questions and optional post-attempt hints, not a numerical score, proof of retained learning or an exam prediction. No concerns returned is not a pass.

Without a configured evaluator, or on invalid/unavailable responses, writing is saved and explicitly unassessed. Retry is explicit and reuses the same committed artifact. Neither a fallback pattern matcher nor concept-check scores substitute for prose assessment. Different-task observations cannot establish improvement merely by comparing counts of concerns.

## Limits

The finite bank contains 14 globally identified topics: ten suitable across the goal profiles and four adult-context topics. Goal or difficulty relabelling never gives a task a new identity. Within the current learner record, previously reserved IDs/families remain used.

Authored topics are candidate practice, not official Grade 7/CAT/GRE/GMAT test specifications. Goal and challenge selections are preferences, not measured levels. The bank is finite, and exhaustion must stop fresh allocation rather than recycle topics. No provider is activated, no real learner data is accepted, no audio is collected, and no human content validation is claimed.

This closes a workflow gap, not the research validation gap for reliable natural-writing assessment. Automatic cross-draft improvement judgments, calibrated placement, semantic plagiarism detection and a comprehensive speaking curriculum remain outside this change.
