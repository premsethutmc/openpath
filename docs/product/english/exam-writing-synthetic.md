# Exam writing: synthetic contract rehearsal

The exam diagnostic preview keeps learner writing on the device and does not assess it. Its separate synthetic example demonstrates a future narrow observation-to-teaching flow without submitting that writing to any model.

## Earlier two-area offline example

- The demonstration uses an invented, fixed sample and a local simulated gateway response. It is not a live model evaluation.
- The response passes the existing v2 gateway provenance and observation validation before use.
- An observation is a tentative concern, never a diagnosis. Independent fixed checks determine only whether practice is useful on those particular items.
- Subject–verb agreement and a/an are the only check areas. Definite/zero articles, broader writing quality, exam readiness, mastery and scores remain unverified.
- Repeated items are practice, not fresh evidence. A lesson is not proof of improvement.
- No API key, provider configuration, payment, real learner transmission or backend gate change is part of this feature.

## Before real writing can be assessed

The synthetic gateway implementation below is now available. Permitted learner-data handling, approved provider/security configuration, rigorous AI/content review and evaluated linguistic accuracy are still needed. Passing these software fixtures proves contract behavior only, not diagnostic accuracy. Never replace these checks with an assertion that a hosted model is reliable merely because its JSON is valid.

## Complete journey (2026-11-18)

`?experience=exam-diagnostic&mode=synthetic` now rehearses reading → invented natural writing → validated observations → deterministic independent checks → targeted teaching → fresh reassessment. The earlier two-area offline example remains available separately. Initial reading/writing is intended to take about ten minutes; follow-up takes longer.

The complete journey covers four narrow areas: subject–verb agreement, a/an, source fidelity and evidence-to-claim reasoning. Two independent checks are required per proposed writing area. Mixed answers remain inconclusive. Teaching is followed by a separate two-item bank, never reused verification items. Reading mistakes have their own lessons and new transfer questions. Immediate performance is not evidence of retention or teaching causality.

Default mode is a fixed invented paragraph and a clearly labelled simulated response, with no network call. Optional server mode uses the existing shared essay API with `openpath.exam-writing@1`, a server-owned prompt and source context. The endpoint remains developer-only, synthetic-only and subject to shared admission limits. No provider was enabled, no real learner data sent, and no paid call made for this implementation. Server failures fail closed, without a simulated assessment fallback.

Writing and responses are memory-only; exposed item IDs persist on this device to prevent reused checks being reported as fresh. Reload discards the sitting; restart retains exposure history. The public pilot still refuses this route. This is a developer rehearsal, not permission to use real learners. Linguistic calibration, rigorous AI/content review, privacy approval and real-device acceptance remain prerequisites for learner use. External educator approval is not a required gate; do not claim human validation.

Tests: `node --import tsx --test src/english/logic/exam-diagnostic/*.test.ts` in frontend; `node --test e2e/exam-journey.test.mjs` against the normal English preview; backend `evaluation` test suite. Browser tests use synthetic local fixtures only.

## Evidence and repeat-use improvements (2026-11-18)

The next milestone adds a second independent verification and reassessment form per writing area. Selection takes an entire unseen pair; a partly exposed pair is skipped, never mixed with other forms. Banks remain finite and uncalibrated. Exhaustion is named per skill rather than reported as success.

After independent checks finish, a review explains each selected and expected answer and gives a bounded next step. Optional own-writing revision is memory-only and explicitly unassessed: completing it does not change scores or establish writing transfer. Reading follow-up is also accessible after a failed writing analysis; if opened, later writing retries are labelled supported practice. Validated not-observable coverage is retained instead of silently discarded.

Still open: more reading passages and transfer forms, deeper reading teaching, genuinely independently assessed natural-writing transfer, wider language coverage, measured diagnostic accuracy and delayed retention. Existing English-core retention/planner modules should be reused when an approved learner-mode integration is built, not duplicated into a synthetic mastery ledger. AI/content review is required; external educator approval is not an owner-required gate, and no human validation is claimed.


## Guided teaching depth (2026-11-18)

Each targeted writing area now has a worked example with explicit reasoning steps and a separate guided practice question. Learners can request a hint, retry after an incorrect answer or deliberately reveal the worked answer. Incorrect feedback does not immediately expose the key. The old read-acknowledgement cannot unlock reassessment: the supported lesson must reach its own completion state first.

This follows the existing English-core essay lesson programme’s distinction between intervention progress and assessment evidence. No synthetic mastery ledger is created. A correct guided response, hint, reveal or lesson completion never alters the independent check score. Guided content disappears before the separate fresh unaided reassessment. Teaching examples and questions are distinct from every verification/reassessment form.

These are narrow authored worked examples, not calibrated courses. Natural-writing revision remains unassessed, and delayed retention/general writing transfer remain unestablished. Content underwent AI review; no external educator or human validation is claimed or required as a gate.


## Deeper reading teaching (2026-11-18)

The four reading follow-up skills now use the same supported-lesson state machine and UI as writing: a worked passage with explicit reasoning, a distinct guided question, optional hint, incorrect-answer retry and deliberate answer reveal. The unaided transfer question stays locked until supported completion. Guided work does not enter the transfer results or exposure history, and its answers/hints disappear when the independent question begins.

Worked/guided passages are distinct from the original library task, legacy practice and private transfer bank. Correctness in supported practice remains intervention progress only, following the existing English-core lesson/evidence boundary. AI/content review is not human validation or calibration. Reading still has one independent transfer item per skill; more passages, equivalently calibrated forms, independent natural writing and delayed retention remain open.
