# Independent argument writing returns to teaching

The existing loop already supports original, for/against and revised writing;
exact-source concept probes; lessons; assisted practice; fresh verification and
later retention checks; and a reserved independent new-topic writing task.

Previously, feedback on the independent attempt stopped in its history panel.
It could not reach the own-word practice or concept-referral panels. Completed
independent attempts now supply those panels, with source topic/stage retained,
within the selected goal and difficulty. They remain available in later cycles.
A latest unavailable response removes the current referral, not saved historical
practice. Stale feedback IDs cannot attach new practice.

A new concern does not reset an existing concept plan, its evidence, or its review
clock. Concept results remain separate from writing estimates. A learner can
work in their own words and then write a new argument; no answer is supplied.
The original independent artifact and its unaided declaration are immutable.
Coaching after submission is supported practice, not a retrospective change to
that declaration or proof of improvement. An old concern describes that attempt,
not necessarily a present weakness.

## Checks and limits

No live provider call or real learner text is used. Tests cover the complete
mocked transfer concern → probe → lesson → guided practice → fresh check path,
source-estimate isolation, reload, next-cycle persistence, goal isolation and
stale-feedback refusal. Existing transfer tests cover reservation and active-task
practice blocking. The hosted browser test checks post-retry referral, own-word
saving and concept-probe entry. Local browser execution remains subject to the
executor's socket restriction; hosted CI must pass before merge.

This is plumbing validation, not validation of the model's semantic judgment.
The workspace remains synthetic/developer-only. API concerns remain tentative;
no findings is not a clean bill of health. Finite authored checks do not establish
argument soundness or exam readiness. Active-attempt coaching isolation is UI
hiding plus workspace mutation guards, not proctoring or a cross-tab concept
controller lock. Previous independent concerns are not automatically retired on
success elsewhere; they remain explicitly labelled historical-source concerns.
