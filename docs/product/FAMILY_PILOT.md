# The hosted server for a real learner (family-pilot@1)

The demo's device mode (DEVICE_MODE.md) keeps a record in one browser. A real learner needs the record kept: on a server,
in a database, reachable from any device, and readable (with the parent's permission) to improve the product. The server
already existed and is tested (accounts, learners, records, server-side grading); what was missing was somewhere to run it
with a database that lasts.

## What it is

One private site, one origin:

- the site password first (nothing is served before it), as on the demo;
- then OpenPath's own parent account (email and password), and the learners under it;
- the welcome screen with the English and Maths tiles; a learner can be added from either;
- records in the owner's own PostgreSQL database (Neon's free plan), reached only over an encrypted connection.

Files: `deploy/pilot/Dockerfile`, `deploy/pilot/start.sh`, `backend/config/pilot.py`, `render.pilot.yaml`. It is the preview
deployment (`deploy/preview`, synthetic data only) with one difference that matters: the preview ignores `DATABASE_URL` and
falls back to a throw-away file; the pilot refuses to start without its PostgreSQL database, so a real record can never land
in a file the next deploy discards.

## Setting it up (owner)

1. Neon: create a free project (region Singapore), copy its connection string.
2. Render: the service `openpath-family` (free, Docker, Singapore, branch `main`, deploys only when asked). In its
   Environment set `DATABASE_URL` to the Neon string and `DEMO_PASSWORD` to a site password of your choosing. The two secrets
   (`DEMO_SESSION_SECRET`, `DJANGO_SECRET_KEY`) are generated by Render.
3. Deploy. `start.sh` applies the database migrations, checks the settings and the grader bundle, then starts.
4. Open the site, enter the site password, choose English, create the parent account, then open Maths and add the learner.

Neither the connection string nor the passwords are committed, logged, or sent through chat.

## What to expect

| | |
|---|---|
| First visit after a quiet spell | Slow: a free Render service sleeps after about 15 minutes without visitors and takes about a minute to wake; a Neon database also wakes on first use |
| Progress | Kept in the database; the same on any device after signing in |
| Grading | The server's recorded decision is what is shown (mode `shadow`, as approved for the preview) |
| Forgotten account password | There is no mail service, so no reset link can be sent. Keep the password safe; it can be reset by hand in the database if needed |
| Backups | Neon's free plan is not a backup. The parent can export a learner's record (Me → export in English; `/api/pupils/<id>/export/`). A scheduled backup is not built |
| Who can read a record | The parent. A developer only if the parent turns on sharing for diagnostics for that learner (every look is logged) |
| Written answers | Saved; marked only by an educator account, which the pilot does not have yet |

## Checked

- `backend/config/test_pilot_settings.py` (3): no database → refuses to start; debug → refuses; with a database → PostgreSQL,
  encryption required whatever the address says, model services off, server clock.
- By hand, in a headless browser against the same one-origin server pair (the gate server and Django) with a test database:
  site password → welcome tiles → English → create parent account → Maths → add learner → Board CISCE, Grade 5 → Start
  learning (62 skills) → answer → stored on the server with the server's decision "correct".
- NOT checked here: the Docker image build and the connection to Neon. This environment has no Docker daemon and no database
  driver; the image is the preview's, which has built and run on Render before. The first deploy is the test: `start.sh`
  stops with a clear message if anything is missing.

## Before a child uses it

- The owner holds the parent account and decides what name is shown (a first name or nickname is enough).
- This is an early version: lessons and questions are machine-checked, not reviewed by a teacher.
- Free plans change. If Render or Neon change theirs, the record should be exported first.

## Signing in once (one-account@1)

- Maths has its own "Create an account" on its sign-in screen; a parent is never sent to another app to register.
- A parent's sign-in lasts 180 days on a device; the site password is asked once a year per device.
