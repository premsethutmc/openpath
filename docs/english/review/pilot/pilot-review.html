lesson EN.FND.SPL.inflections#plain

teaching · lesson: plain · existing lesson, examples revised in PR #24

Adding -s, -ed and -ing
Most words just take the ending. The base word does not change: look → looks, looked, looking.
Example: kick → kicks, kicked, kicking
Example: help → helps, helped, helping
Tip: Say the base word first, then add the ending you hear.
Check: Which is correct? (paint + -ing) Options: paintting / painting / painteing

Key: painting: paint + -ing = painting. Nothing changes in paint.

lesson EN.FND.SPL.inflections#es_plural

teaching · lesson: es_plural · existing lesson, examples revised in PR #24

Adding -es
Words ending in s, x, z, ch or sh add -es, because you can hear an extra syllable: fox → foxes, catch → catches.
Example: dress → dresses
Example: brush → brushes (you can hear 'brush-iz')
Tip: If you can hear an extra 'iz' sound at the end, write -es.
Check: Which is correct? (church + -s/-es) Options: churchs / churches / churchies

Key: churches: church ends in ch, so it takes -es: churches.

lesson EN.FND.SPL.inflections#double_short

teaching · lesson: double_short · existing lesson, examples revised in PR #24

Doubling the last letter (short words)
In a one-syllable word with one short vowel and one final consonant, double the consonant before -ing, -ed, -er or -est: plan → planning, drop → dropped, thin → thinner.
Example: grab → grabbing
Example: hop → hopped (not hoped, which comes from hope)
Tip: Two consonants keep the vowel short: hopping (short o), hoping (long o).
Check: Which is correct? (sit + -ing) Options: siting / sitting / sitteing

Key: sitting: sit has one short vowel and one final consonant, so the t doubles: sitting.

lesson EN.FND.SPL.inflections#drop_e

teaching · lesson: drop_e · existing lesson, examples revised in PR #24

Dropping the silent e
If a word ends in a silent e, drop the e before an ending that starts with a vowel (-ing, -ed, -er): bake → baking, smile → smiling.
Example: ride → riding
Example: dance → dancing
Tip: Keep the e before an ending that starts with a consonant: hope → hopeful.
Check: Which is correct? (write + -ing) Options: writeing / writting / writing

Key: writing: write ends in a silent e, which is dropped before -ing: writing.

lesson EN.FND.SPL.inflections#y_to_i

teaching · lesson: y_to_i · existing lesson, examples revised in PR #24

Changing y to i
If a word ends in a consonant + y, change the y to i before -ed, -er, -est or -es: hurry → hurried, funny → funniest, lady → ladies.
Example: fry → fried
Example: busy → busier
Tip: Keep the y before -ing (crying), and after a vowel (play → played).
Check: Which is correct? (try + -ed) Options: tryed / tried / tride

Key: tried: try ends in consonant + y, so the y changes to i: tried.

lesson EN.FND.SPL.inflections#stress_doubling

teaching · lesson: stress_doubling · existing lesson, examples revised in PR #24

Doubling in longer words
In a longer word, double the last consonant only if the last syllable is stressed: permit → permitted, refer → referred.
Example: admit → admitted (ad-MIT: stress at the end)
Example: regret → regretting
Tip: Say the word aloud and listen for which syllable is strongest.
Check: Which is correct? (commit + -ed) Options: comited / committed / commited

Key: committed: com-MIT is stressed on the last syllable, so the t doubles: committed.

lesson EN.FND.SPL.inflections#no_double_unstressed

teaching · lesson: no_double_unstressed · existing lesson, examples revised in PR #24

When not to double
If the stress is on the first syllable, do not double: limit → limited, enter → entering, offer → offered.
Example: happen → happened (HAP-pen: stress at the start)
Example: cover → covering
Tip: Compare: preFER → preferred, but OFfer → offered.
Check: Which is correct? (garden + -ing) Options: gardenning / gardening / gardining

Key: gardening: GAR-den is stressed on the first syllable, so the n does not double: gardening.

lesson EN.FND.SPL.inflections#exceptions

teaching · lesson: exceptions · existing lesson, examples revised in PR #24

Tricky endings
Three patterns to learn: ie becomes y before -ing (die → dying); add k after a final c (mimic → mimicked); and in British spelling, a final l after one vowel doubles (travel → travelled).
Example: die → dying
Example: mimic → mimicking
Example: cancel → cancelled (American spelling: canceled)
Tip: OpenPath teaches British spelling, and also accepts American spellings as correct.
Check: Which is correct? (tie + -ing) Options: tieing / tying / tiing

Key: tying: tie ends in ie, which becomes y before -ing: tying.

In late spring, a crowded honeybee colony may split in two. The old queen leaves with about half of the workers, and the swarm hangs from a branch while it searches for a new home. The search can last from a few hours to several days.

The queen does not choose the new home. Instead, a few hundred older bees, called scouts, fly out to inspect possible sites such as hollow trees. A good site must be dry, well above the ground and large enough to store honey for the winter. When a scout returns, she performs a "waggle dance" on the surface of the swarm. The angle of the dance shows the direction of the site, and its length shows the distance.

Scouts that have found better sites dance for longer and with more energy, so more bees go to inspect those sites. Over time, support gathers around one location. When enough scouts are waiting at the same site, the whole swarm takes off and flies there. Researchers have found that swarms usually choose the best site available, even though no single bee compares all the options. Some scientists believe human committees could learn from the way bees reach agreement.
