## The problem

`MATH.algebra.linear-equations` is one competency in production (`evidence.ts skillEvidence`). The module mixes five question families:

| Family | Questions | Sub-skill |
|---|---|---|
| `lin` | ax + b = c | two-step |
| `lboth` | ax + b = cx + d | variables on both sides |
| `lbrk` | a(x + s) = cx + d | brackets |
| `auleq`, `aulwp` | forming an equation from a situation | supporting |

One-step equations (`ahone`) are a separate competency, `MATH.algebra.linear-intro`.

Production status counts any two distinct right first answers given alone. Its delayed check uses the module's retention list, which holds only `lin` and `auleq` questions. Success on one family can therefore stand for all of them. Doc 3 gives the measured cases.
