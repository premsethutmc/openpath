# Mathematical numerals

Kalam Light (weight 300), Latin subset, unmodified `kalam-latin-300-normal.woff2` from `@fontsource/kalam@5.3.0` (Google Fonts Kalam v18). Upstream: https://github.com/google/fonts/tree/main/ofl/kalam and https://github.com/itfoundry/kalam .

SHA-256: `19f8586a22fbcb870f9d2490381d76b9f2e868c56e44b7bbc28d9efe05522a41`.

Compared Caveat Regular, Kalam Regular and Patrick Hand Regular at 40–42px using `379 ÷ 3`, `126`, `1005`, `432`, `18`, `36`, `96` and all ten digits. All three candidate licences were checked as OFL-1.1. See [the rendered comparison](../../../../docs/product/mathematical-writing/approved-notebook/font-comparison.png).

Kalam Light most closely matches the supplied reference's tall, slightly sloping pen strokes, oval zero, open seven and descending nine. Caveat is more abbreviated and horizontally spread; Patrick Hand is more upright and rounded. Kalam is a handwriting font with suitable mathematical numerals, not a symbolic mathematics typesetting engine. UI text remains in the existing clean system sans-serif.

**Alignment comes from the grid.** Numeral advance widths vary. Each visible digit is centred in an explicit column, including digits inside multi-digit products; no monospace assumptions, letter-spacing tricks or width-based scoring are used. The font applies only to mathematical writing, not explanations, buttons or navigation. The standard minus sign remains available via the font/browser symbol fallback.

A second side-by-side weight check compared Kalam 400, Kalam 300 and Caveat 400. Kalam 300 at 38px was selected after the 400-weight browser capture appeared heavier than the approved pen strokes; see [weight comparison](../../../../docs/product/mathematical-writing/approved-notebook/font-weight-comparison.png).
