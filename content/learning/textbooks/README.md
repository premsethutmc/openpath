# Sample textbooks (synthetic)

These are **not real textbooks**. They are short, original outlines written for OpenPath testing, in the structured
format the curriculum ingestion parser reads (`packages/learning/src/curriculum.ts`). They are CC0. Page numbers refer
to these imaginary books only. No NCERT, Tamil Nadu or other board text is reproduced.

Format:

```
---
title / grade / subject / board / edition / publisher / licence      (front matter, one "key: value" per line)
---
# Chapter <n>: <title> (pp. <a>–<b>)
## Learning outcomes
- <outcome text> (p. <n>)
## Worked examples
- <title> (p. <n>)
## Exercises
- <reference> (p. <n>)
```
